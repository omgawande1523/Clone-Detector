1Enrol a reference voice (optional)

Gives the system a known-good voiceprint of the person being protected — the CEO, or a specific customer — so it can tell "not this person" apart from "sounds synthetic".

Click or drop a clean .wav — 10–20 seconds of this person speaking
⚠ Enrolment is unauthenticated in this deployment (ENROLL_TOKEN not set): anyone who can reach the server can overwrite a voiceprint. Overwrites are written to the audit trail.

2Call context (optional)

Metadata a contact centre already has. It sharpens a verdict but can never raise an alert on its own — a suspicious-looking call is not evidence that a voice was cloned.

3Analyse the call

True real-time path. Your microphone is captured in 5-second segments; each one is scored the moment it is recorded and the gauge moves while you are still talking. Enrol a voice in step 1 first so the speaker check has something to compare against.

idle

Batch analysis of a recording — useful for testing against fixture files. Split into 5-second windows and scored through the same pipeline as the live path.
